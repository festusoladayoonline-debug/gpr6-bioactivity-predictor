# Setup Guide

## Prerequisites
- Python 3.x
- Required libraries: `numpy`, `scikit-learn`, etc.

## Installation Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/festusoladayoonline-debug/gpr6-bioactivity-predictor.git
   cd gpr6-bioactivity-predictor
   ```
2. Install the required libraries:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the setup script:
   ```bash
   python setup.py install
   ```
4. Test the installation by running:
   ```bash
   python -m gpr6
   ```

## Troubleshooting
- Ensure that all prerequisites are met.
- Consult the [issues page](https://github.com/festusoladayoonline-debug/gpr6-bioactivity-predictor/issues) for common problems.
